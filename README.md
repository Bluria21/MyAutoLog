#  **MyAutoLog**

  Приложение для автомобилистов, созданное с нуля на Kotlin + Jetpack Compose.
MyAutoLog помогает отслеживать пробег, замену деталей и состояние автомобиля — всё в одном месте.

-------

# Цель проекта

Создать удобное и современное Android-приложение, которое позволит пользователям:

* добавлять автомобили и управлять ими;

* вести учёт пробега;

* сохранять записи о заменах и обслуживании;

* получать напоминания о предстоящем ТО.

# Основные функции

 Добавление автомобиля с фото, моделью и годом выпуска

 Учёт замен деталей и сервисных записей

 Сохранение данных локально (Room + DataStore)

 Поддержка смены языка (русский / английский)

 Современный дизайн на Jetpack Compose
